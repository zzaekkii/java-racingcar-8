# java-racingcar-precourse

### 📌 요구사항 요약
주어진 턴마다 여러 자동차들을 전진하거나 멈추고,
턴이 모두 끝난 뒤 가장 멀리 이동한 자동차들을 출력하기
<br/>

### 📝 구현할 기능 목록
#### 1. 자동차 이름 입력
- 조건
- [x] `Console`의 `readLine()`으로 입력받기
- [x] 자동차 이름은 5자 이하
- [x] `,`쉼표로 각 이름을 구분
- 예외
- [x] 이름에 알파벳과 숫자가 아닌 문자가 있을 경우
- [x] 동일한 이름이 중복 입력된 경우
- [x] `,` 쉼표 외 구분자가 사용된 경우 (사실상 길이 검사에 포함됨)

#### 2. 반복할 턴 수 입력
- 조건
- [x] `Console`의 `readLine()`으로 입력받기
- 예외
- [x] 음수이거나 0일 경우
- [x] 숫자가 아닐 경우

#### 3. 각 자동차 별 전진/정지 판별 (경주)
- 조건
- [x] `Randoms`의 `pickNumberInRange()`로 0-9 사이의 난수 추출하기
- [x] 추출된 난수가 4 이상일 경우 전진
- [x] 각 회차마다 자동차 이름과 누적된 전진 상태 출력

#### 4. 우승자 출력
- 조건
- [ ] 누적된 이동거리가 가장 큰 자동차들을 출력
- [ ] 공동 우승자는 `,` 쉼표로 구분해 입력 순서대로 출력

<br/>

---
### 💡 요구 사항에 기재되지 않아 스스로 판단한 규칙
- 턴 입력에 최대값 제한이 없으므로 `BigInteger`를 이용한다.
- 자동차 이름은 알파벳이나 숫자로만 구성할 수 있다.
- 자동차 이름 중복이나 이름 내 공백은 허용하지 않는다.
- `,` 쉼표 외 구분자는 예외 처리한다.
- 턴 수는 음수나 0이 아닌 양수이다.
- 우승자가 여러 명일 경우, 출력 순서는 입력 순서를 따른다.
